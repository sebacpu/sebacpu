# Sebastián Aravena

Air traffic controller and software developer based in Santiago, Chile.

I work the radar at ACC Santiago (DGAC Chile) and build software the rest of the time, mostly AI tools for aviation and for small businesses. Founder of [Edvance](https://edvance.cl), a web and software studio.

## What I'm building

- **[Edvance OS](https://edvance.cl)**: multi-tenant CRM and workspace for Chilean SMEs.
- **AeroBrief**: RAG assistant that answers questions over Chilean aeronautical regulation, with citations to the source documents.
- **EVA**: self-hosted personal assistant running on a home server. Telegram interface, speech-to-text, scheduled jobs, local LLM fallback.
